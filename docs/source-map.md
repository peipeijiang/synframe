# 来源与能力映射

## 100x 开源技能

来源：kezd088/100x-skill-tiktok，commit 59089836505822ecf9195404a3d746a63def33d5，MIT，原件及许可证在 vendor/100x。

| 技能 | 输入与输出 | 当前使用方式及边界 |
|---|---|---|
| video-reverse | 本地视频 → 有时间戳的画面、音频证据与 reverse.json | 原样收录，可单独运行；结构验证不保证视觉效果 |
| segment | 英/西语脚本 → 段落、镜头目的、气口标记 | 原样收录；适用范围及严格 schema 见原技能 |
| localize | 源文案 → 墨西哥西语本地化版本 | 原样收录；私有原始语料不随仓库分发 |
| persona | 脚本 → 有来源引用的人物及场景 | 原样收录；逐字匹配不能验证语义是否反转 |
| exaggerate | 脚本 → 夸张和反差设计 | 原样收录；不得把未验证的宣称作为事实 |
| search-query | 产品、人设 → 平台视觉参考查询 | 原样收录；关键词护栏不能覆盖所有表达 |
| visual-fission | 锁定素材及文案 → 视觉变体矩阵 | 原样收录；部分叙事真实性需要人工判断 |
| prompt-compose | 模板和变量 → 模型提示词 | 原样收录；默认英文对白限制不能直接用于 es-MX；Synframe 尚未实现目标语言适配器 |
| tiktok | 需求 → 技能路由 | 原样收录；不生成内容 |

各技能的 metadata.json、schema.json、workflow.md、sources.md 与脚本是其输入输出与校验的权威来源。requires_data 中的项目依据各技能说明可能是来源记录，不应一概理解为必需的运行时数据。

## AdMuse

AdMuse（github.com/peipeijiang/ad-muse）为参考来源；仓库 skills/ad-muse 测试 19 项通过。以下为设计复用，而非已移植的适配器：

| 参考能力 | Synframe |
|---|---|
| SKU 原图为权威、互补参考图 | 主技能明确要求 |
| 镜头动作与空间风险决定分镜、预演 | 主技能明确要求 |
| H3 与 Omni 的不同请求边界 | 收录 vendor/admuse/prepare_request.py 及参考路由校验；合成请求结构测试通过，不代表渠道实测通过 |
| 参考视频完整视听、原语言 ASR | 创意技能与 100x reverse；原样收录 MIT 许可的本地 Whisper 脚本及许可证在 vendor/admuse |
| 技术、创意与人工听审分开 | QC 技能和素材筛选明确分开 |

上游公开仓的校验规则和本机参考可能随时间变化；下次付费运行前重新核实模型和渠道能力。
